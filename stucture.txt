event-qr-system/
├── docker-compose.yml       # กำหนดค่าและจัดการ Multi-container Docker สำหรับรันแอปพลิเคชัน Node.js, MySQL และ phpMyAdmin พร้อมเซ็ต Timezone (Asia/Bangkok)
├── Dockerfile               # ไฟล์สำหรับสร้าง Docker Image ของฝั่ง Backend (Node.js) ติดตั้ง dependencies และกำหนดค่าเริ่มต้น
├── init.sql                 # สคริปต์ SQL เริ่มต้นสำหรับสร้างตารางฐานข้อมูล (events, attendees, checkin_logs, users) และบัญชีแอดมินเริ่มต้น
├── package.json             # ไฟล์จัดการแพ็กเกจและไลบรารีของ Node.js (เช่น express, mysql2, nodemailer, qrcode, exceljs, multer)
├── server.js                # ไฟล์ Backend หลักของระบบ รัน Server, เชื่อมต่อ MySQL, จัดการ API ทั้งหมด (Login, Event CRUD, Import/Export Excel, Register, Check-in)
└── public/                  # โฟลเดอร์เก็บไฟล์ Static สำหรับฝั่ง Frontend
    ├── admin.html           # หน้าจอเว็บสำหรับผู้ดูแลระบบ (System Admin และ Supervisor) ใช้จัดการ Event, นำเข้า Excel และออกรายงาน
    ├── login.html           # หน้าจอเข้าสู่ระบบ (Login) รองรับการตรวจสอบสิทธิ์ตามบทบาท (ADMIN, SUPERVISOR, SCANNER)
    ├── register.html        # หน้าจอลงทะเบียนเข้าร่วมงานของผู้ใช้งาน พร้อมสร้าง QR Code และส่งอีเมลอัตโนมัติ
    ├── scanner.html         # หน้าจอสำหรับสแกน QR Code เช็คอินเข้างาน (รองรับสแกนผ่านกล้องและกรอกรหัสด้วยตนเอง)
    └── js/                  # โฟลเดอร์เก็บไฟล์สคริปต์ฝั่ง Frontend
        ├── admin.js         # ควบคุมการทำงาน การแสดงผล และการเรียก API ในหน้า admin.html (จัดการ Event, User และรายงาน)
        └── login.js         # ควบคุมการส่งข้อมูลตรวจสอบรหัสผ่านและการเปลี่ยนหน้าตามสิทธิ์ในหน้า login.html
